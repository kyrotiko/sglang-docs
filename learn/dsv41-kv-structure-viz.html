这里会显示：本次 attention 实际读了哪些 token / 槽。

SWA

最近 W 个 token 保留原样 KV。看得最清，但只覆盖一小段窗口。

544 B/token · mxfp8

C1 / C2

把历史 token 压成 latent：ratio 2 每两个 token 一槽，ratio 1 每 token 一槽。

320 B/槽 · mxfp4

indexer K

专门用来打分的压缩 K，不是最终 attention 的 KV。越小，打分越便宜。

64 B/token · packed FP4

indexer scale

FP4 K 的块缩放，每 32 个值一个。没有它，K 就没法还原，分数会乱。

4 B/token · E8M0

把它们拼起来

ratio > 0 的层：attention 读取 = 窗口侧（最近 W 个 token 的原样 KV）
  + 压缩侧（indexer 打分 → top-k → 选中的 C1/C2 槽）
top-k 来自 Q · (K × scale) ，K 只有 kv_source 层持有，consumer 层共享。

一句话：SWA 管近处，C1/C2 管远处，indexer K/scale 负责决定看远处的哪些位置。

基于 sglang@dsv41-a5 的 layers/attention/dsv4/dsv41_sparse.py、 hardware_backend/npu/dsv4/dsv4_memory_pool.py、 hardware_backend/npu/attention/ascend_dsv4_backend.py 整理。 演示数字为教学简化；真实默认值：window=128、index_topk=512、index_head_dim=128、64 个 index head（以 checkpoint 为准）。
