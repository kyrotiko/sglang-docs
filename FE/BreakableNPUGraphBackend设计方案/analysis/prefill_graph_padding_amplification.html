为什么把 bucket 调小救不了 16× 放大

开图后 runner 会强制 MAX_LEN：把 16 个 DP rank 全部对齐到同一个 bucket。 allgather 再把这个形状乘以 rank 数。所以放大器是 rank 的个数， 不是 bucket 的大小。

关图 · SUM_LEN

每个 rank 跑自己的真实 token；空转的 rank 贡献 0 行

MoE 处理行数 = Σ 真实 token

开图 · MAX_LEN

所有 rank 被 pad 到同一个 bucket，空转的也要跑满

MoE 处理行数 = 16 × bucket
